# 霖州往事 · 悬浮手机

为《霖州往事》角色卡制作的二创悬浮手机组件，提供微信风格的私聊、群聊和表情包功能。

## 前置要求

- SillyTavern 已安装 **JS-Slash-Runner** 扩展

## 安装方法

两个版本二选一，都在仓库根目录：

- **在线版 `linzhou_phone_online.json`（推荐）**：脚本库里只放一段加载器，打开酒馆时自动拉最新脚本。作者更新后你什么都不用做。
- **离线版 `linzhou_phone_offline.json`**：整段脚本嵌在里面，不联网也能开手机（壁纸和头像仍需联网）。更新要重新导入。

步骤：酒馆助手 → 脚本库 → 导入 JSON → 确保脚本已启用 → 打开霖州往事角色卡，右下角出现墙头探头的猫即成功。

## 功能

### 悬浮球与手机壳

- 右下角悬浮球，点击打开手机
- 手机壳参考贾可默的金属质感设计，配色取自卡片封面油画（天蓝、叶绿、花白、玫粉、墙赭）
- 锁屏带实时时钟和壁纸

### 私聊

支持与全部 9 位 NPC 私聊：

周言、沈锡元、林溪、陆飞、陈悠悠、闻迦、林思菀、蒋默、阿哲

每位角色有独立的说话风格和头像，AI 会根据角色性格生成回复。

### 群聊

4 个群聊，模拟多人同时回复：

- 金华苑扶贫小组（周言、沈锡元、你）
- 霖附摸鱼自留地（周言、沈锡元、陆飞、林溪、你）
- 高三（2）班（全部 9 位同学 + 你）
- 霖附吃瓜二手交易市场（校园公共群）

### 表情包

内置原卡全部 88 张表情包，聊天界面底部点笑脸图标打开表情包面板，点击即发送。AI 回复也可以使用表情包。

### 技术特性

- **独立 API 生成**：手机消息通过 generateRaw 独立生成，不影响主线文本格式
- **主线上下文同步**：手机聊天内容自动注入主线 AI 上下文（带隐私框架：私聊内容仅当事人知晓）
- **主线剧情感知**：生成回复时会读取主线最近 8 条消息，保持剧情连贯
- **聊天记录持久化**：存储在聊天变量中，每个聊天会话独立保存

## 逃生阀

如果手机卡住或悬浮球不见了：

- **长按悬浮球 1.5 秒**：强制关闭手机并重置状态
- **点击 📱手机 脚本按钮**：在酒馆助手的脚本按钮栏中，点击可切换手机显隐

## 壁纸

壁纸就是卡的封面油画，托管在本组件的 GitHub 仓库里，通过 jsDelivr 多域备胎加载（国内直连也走得通）。所有域都不通时退回一张油画色渐变，不会空白。

想换壁纸：把图片放进仓库，改脚本顶部的 `WALL_REPO` / `WALL_REF`，或直接把 `WALL_SRCS` 数组换成你自己的图片链接。

## 文件

- `linzhou_phone_online.json` — 在线版，导入用
- `linzhou_phone_offline.json` — 离线版，导入用
- `dist/phone.js` — 脚本本体（在线版运行时从这里拉）
- `悬浮球预览.html` — 悬浮球三种状态的预览页
- `cover.jpg` — 壁纸

在线版的版本指针走 jsDelivr@提交号，发版即生效，不受 CDN 缓存影响。
